# Neoware Public Research Notes

Neoware describes itself as a specialist Data to Intelligence solutions provider combining consulting, Data Engineering, AI/ML, GenAI and BI.

Public Data Engineering themes include diverse source integration, incomplete/inconsistent data, scalable data platforms, lakehouse implementation, migration, governance and data quality.

Neoware publicly describes a Data Validation and Reconciliation (DVRC) accelerator. This portfolio project is **not** a reimplementation of that proprietary tool; it independently demonstrates the underlying engineering concept using synthetic data.
